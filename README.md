# Reshma's Portfolio Website

A modern, professional portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Modern Animations**: Smooth scroll animations and interactive elements
- **Professional Layout**: Clean, standard design suitable for professional use
- **Contact Form**: Interactive contact form with validation
- **Skills Showcase**: Detailed descriptions of technical skills
- **Experience Section**: Professional timeline and project highlights

## Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with animations and responsive design
- **JavaScript**: Interactive animations and form handling
- **Font Awesome**: Icons for skills and social links
- **Google Fonts**: Inter font family for professional typography

## Setup Instructions

1. Place your professional image in the root directory and name it `profile-image.jpg`
2. Open `index.html` in your web browser
3. Customize the contact information in the HTML file as needed

## Image Requirements

- **File Name**: `profile-image.jpg`
- **Recommended Size**: 300x300 pixels or larger (square aspect ratio works best)
- **Format**: JPG, PNG, or WebP
- **Quality**: High resolution for professional appearance

## Customization

### Contact Information
Update the following in `index.html`:
- Email address in the contact section
- Phone number
- Social media links
- Any other personal information

### Colors and Styling
The website uses a professional blue and purple color scheme. You can customize colors by modifying the CSS variables in `styles.css`.

### Content
- Update the about section with your personal story
- Modify project descriptions to match your actual work
- Add or remove skills as needed
